Overview:
This project implements and evaluates a trading strategy using historical stock market data.
The goal is to analyze performance metrics such as returns, Sharpe ratio, and drawdowns, while also visualizing strategy behavior compared to a benchmark (e.g., S&P 500).

Features:
1. Data collection via Yahoo Finance (yfinance)
2. Technical indicators (Moving Averages, RSI, etc.)
3. Signal generation (buy/sell rules)
4. Backtesting engine
5. Performance metrics
6. Total Returns
7. Annualized Returns
8. Sharpe Ratio
9. Maximum Drawdown
10. CAGR
11. Alpha (excess return)

    
Visualization of:
1. Equity Curve
2. Drawdown Curve
3. PnL Per Trade
4. Cummulative Returns vs Benchmark (S&P 500)
5. Risk/Reward Scatter (Holding Period vs PnL %)
6. Win/Loss Pie Chart


Tech Stack:
1. Python (3.8+)
   
Libraries:
1. yfinance – stock data
2. pandas / numpy – data processing
3. matplotlib – visualization
4. scikit-learn (optional, for ML-based signals)
5. plotly - making interactive graphs
